## 4. Constraints

- Coding agents only: `.py` → python-coder, `.rs` → rust-coder; never general-purpose. Item 19 splits Rust/JS (rust-coder) vs Python integration test (python-coder) by file boundary.
- Static SVG output for existing charts must be byte-unchanged (item 21 Label routes as Text; item 19 `svg_walk` ignores `anchor`).
- Serde back-compat: `RawAnchor` `#[serde(default)]` → `Chrome`; `Label`/`RawAnchor` cross the core↔WASM JSON boundary safely (version-pinned).
- Item 17 literal semantics: stroke color + width 0 = no visible border; NO call-time width auto-bump.
- Item 19: no new dependency / no SVG parser / no tessellator; overlay stays `pointer-events:none`.
- After code changes invoke `/regression-test` before declaring an item done.
- If any `tests/goldens/**` change: rasterize via `scripts/snapshot-goldens.py` and visually inspect the PNG before committing (CLAUDE.md).
- WASM changes require rebuild: `source ~/.cargo/env && wasm-pack build crates/ferrum-wasm --target web --out-dir ../../src/ferrum/_wasm/`.
