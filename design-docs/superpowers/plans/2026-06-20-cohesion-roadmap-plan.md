## 4. Constraints

- **Byte-identical render output** for every task except C13's intended warn-once. Any golden byte-diff outside an explicitly-blessed regeneration is a regression. Full golden + `cargo test -p ferrum-core` + `-p ferrum-wasm` + full pytest must pass after every task.
- **No public-API change.** `Chart`, all `*_chart`/visualizer functions, all composite classes, and all PyO3 class/function signatures stay identical. After WP-C splits, `from ferrum import *` and the stub/signature-parity test must still pass.
- **C6:** `build_size_scale`/`build_opacity_scale` → `(Option<…>, Vec<RenderWarning>)` (empty Vec — they emit no warnings today); `build_auxiliary_scales` uses `warnings.extend` for all four. Output byte-identical.
- **C7:** tick/segment/rule opacity via `OpacityResolver`; resolved values must equal current hand-rolled logic exactly.
- **C9:** `color_column_loader` + `polar_channel_resolver` reused; each adopter byte-identical.
- **C11:** `general_fallback: bool` → `OpacityFallback::{Standard, BarLike}` enum; serialize/resolve identically (bar = BarLike, others = Standard). Update all `OpacityResolver::load` call sites (the 5 marks + the C7 adopters).
- **C8:** one `encode_serde_value_for_py` helper; `condition`/`sort`/`impute`/`legend`/`axis` getters delegate; output identical.
- **C12:** new test parses a 1-mark chart's packed bytes and asserts the stride matches `_PACKED_INSTANCE_SIZES`; must fail on a deliberately-wrong constant (real discriminator).
- **C5:** one appearance-channel honored-kwargs source of truth; each channel's `sort`/`scheme` membership stays exactly as today (no kwarg gained/lost — verify against current `_honored_kwargs` per channel).
- **C13:** `stroke` dropped when `color` present → warn-once (use the existing `warn_once`); ghost positional channels' docstrings match their real `_honored_kwargs` (remove "reserved for future use" where it actually warns). No silent drop remains undocumented.
- **C10 (folded into C2):** `_Facet` type-safety must serialize to byte-identical facet JSON for every existing case (wrap col/row/field, grid, explicit ncols).
- **C2/C3/C14/C1:** behavior-preserving module decomposition / helper extraction; if a split forces a circular import or a worse coupling, STOP and surface it (spec §11) rather than forcing the line-count win.
- Goldens regenerated by any task are visually inspected before commit (orchestrator blesses PNGs; coders do NOT self-bless).
- No matplotlib; no global mutable state. Build: `unset CONDA_PREFIX && uv run --no-sync maturin develop`. Rust tests need `DYLD_LIBRARY_PATH=/opt/homebrew/Caskroom/miniforge/base/lib`; pytest gets NO DYLD. Source `~/.cargo/env`.
