## Launch-style copy

Ferrum is a statistical visualization library for Python designed around a simple idea: every chart should follow the same mental model. That means layered plots, statistical graphics, model diagnostics, and interactive views all live inside one coherent chart system instead of separate toolchains.

What makes Ferrum unusual is that the development process followed the same logic. The project was built through a spec-first agentic framework where design decisions were fixed early, plans were written before implementation, coding agents handled execution, and review gates plus audit campaigns enforced quality on every phase.  The result was a Rust-backed library with broad chart coverage, interactive rendering, and dataframe interoperability — built in 10 days without giving up architectural discipline.

## Why-now copy

Python visualization still fragments one workflow into too many abstractions: one tool for layered charts, another for interactivity, another for convenience plots, and another for ML diagnostics. Ferrum is an attempt to unify those worlds so users can stay in one coherent chart system from exploration to explanation to model evaluation.

The way Ferrum was built mirrors that same unification instinct. Instead of ad hoc AI coding, the project used a structured agentic framework with a load-bearing spec, implementation plans, coding specialists, commit gates, and repeatable audit campaigns.  The point was not just to move fast, but to move fast without letting the design fracture.

## Technical / builder angle

Ferrum is built around grammar-first charting, first-class statistical transforms, renderer-level interactivity, and model artifacts as data. Under the hood it uses Python as the declaration layer, Rust as the computation layer, Arrow CDI for efficient handoff, and Narwhals for interoperability across the Python dataframe ecosystem.

It was also built with an unusually explicit engineering process: 38 design specs, 42 implementation plans, 13 agent definitions, lightweight and heavyweight review layers, and quality campaigns that audited behavior across rendering, bindings, themes, and visual output.  That makes Ferrum both a plotting library and a practical example of agentic development with strong architectural control.
