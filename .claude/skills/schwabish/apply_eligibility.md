# Eligibility List — Objective Findings the Autonomous Fixer Applies

The `schwabish-fixer` agent (gallery-autonomous mode only) applies a finding from a `schwabish_verdict.md` to `gallery/plots/<row>/ferrum_panel.py` if and only if:

1. The finding has `objective: true` in the verdict's YAML frontmatter, AND
2. The finding's `id` appears in the **Eligible** table below.

Subjective findings (`objective: false`) — and any objective finding whose ID is not in the eligible table — stay in the verdict for user review.

## Eligible findings (auto-applied by `schwabish-fixer`)

| Finding ID | Rubric | Autonomous action |
|---|---|---|
| `T4_auc_label_missing` | T4 | Append `+ AUCLabel()` to the chart construction expression on ROC panels |
| `T4_ap_label_missing` | T4 | Append `+ APLabel()` on PR panels |
| `T4_brier_label_missing` | T4 | Append `+ BrierLabel()` on calibration panels |
| `T4_residual_metrics_missing` | T4 | Add `annotate_metrics=True` kwarg to `residuals_chart(...)` or append a corner `annotate_text` on hand-rolled panels |
| `T4_cell_counts_missing` | T4 | Flip `annotate=True` on `confusion_matrix_chart(...)`, or add a `mark_text` overlay for hand-rolled panels |
| `T4_importance_values_missing` | T4 | Flip `show_values=True` on `importance_chart(...)` |
| `T2_direct_labels_eligible` | T2 | Add a direct-label `mark_text` overlay at line endpoints **and** suppress the legend, only when series count ≤ 4 and labels are short strings |
| `T4_pr_baseline_missing` | T4 | Append `+ annotate_hline(positive_class_rate, stroke_dash=[3, 3])` on PR panels (binary classifiers only) |
| `T4_residual_zero_line_missing` | T4 | Append `+ annotate_hline(0, stroke_dash=[3, 3])` on residuals panels |
| `T4_calibration_diagonal_missing` | T4 | Append a y=x diagonal segment on calibration panels (only if the existing chart construction omits it) |

## Non-eligible findings (advisory only)

| Finding ID | Rubric | Why not autonomous |
|---|---|---|
| `T1_active_title_eligible` | T1 | Title rewriting is subjective; user-facing copy choice |
| `T1_active_title_*` (any variant) | T1 | Same as above |
| `T1_subtitle_eligible` / `T1_subtitle_*` | T1 | Subtitle wording is user-supplied semantic context, never inferable |
| `T3_callout_opportunity` / `T3_callout_*` | T3 | Where to callout depends on data + intent |
| Any finding with `objective: false` | — | Per-finding judgment by `schwabish-judge`; respect the flag |
| Any finding ID not listed in the **Eligible** table above | — | Unknown ID — fixer refuses rather than guessing |

## Idempotence

Before applying any eligible finding, the fixer reads `gallery/plots/<row>/ferrum_panel.py` and checks whether the target primitive is already present. Examples:

- `T4_auc_label_missing` → skip if `AUCLabel(` appears in the file.
- `T4_cell_counts_missing` → skip if `annotate=True` already appears on the `confusion_matrix_chart(...)` call.
- `T2_direct_labels_eligible` → skip if a `mark_text` layer at line endpoints already exists.

Re-running `/schwabish-improve --from-audit` on an already-Schwabish-clean row produces no diff.

## Scope restriction

The fixer is restricted to `gallery/plots/<row>/ferrum_panel.py`. It does **not** edit:

- `src/ferrum/` — figure-level function defaults are Schwabish-SB3's job, not the fixer's.
- `crates/` — Rust changes belong in the design + plan path.
- `tests/` — tests are not autogenerated from verdicts.
- Any file outside `gallery/`.
