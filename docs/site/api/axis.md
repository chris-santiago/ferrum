# ferrum.axis

Per-channel axis configuration.

The `Axis` dataclass controls axis appearance — title, ticks, grid lines, labels,
domain line, and positioning. Pass an `Axis` instance to an encoding channel's
`axis=` parameter, or use `axis=False` to suppress the axis entirely.
